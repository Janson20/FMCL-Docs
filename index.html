FMCL⛏ Fusion Minecraft Launcher

一个功能丰富的 Minecraft 启动器，基于 CustomTkinter 现代化 UI，支持国内镜像加速、多模组加载器安装与版本管理

立即下载
GitHub
🎮

版本管理

浏览并安装所有 Minecraft 版本（正式版 + 测试版）。已安装版本列表支持一键选择和启动，分页浏览可用版本列表。

⚡

国内镜像加速

内置 BMCLAPI 镜像源，国内下载速度大幅提升。一键开关镜像源，覆盖版本清单、游戏资源、库文件等。

🔧

多模组加载器

支持 Forge、Fabric、NeoForge 三种主流模组加载器。安装模组加载器时自动并行安装原版 Minecraft。

🧩

Modrinth 模组浏览

集成 Modrinth API，在线搜索和安装模组。AI 智能搜索优化关键词，精准筛选兼容版本和加载器类型。

📦

整合包安装与开服

支持 .mrpack 整合包安装和服务器部署。并行安装优化，自动下载模组与依赖，版本隔离避免冲突。

🖥

服务器管理

独立的开服标签页，支持下载并启动 Minecraft 服务器。智能 Java 管理，实时日志监控，内存与进程监控。

🌐

陶瓦联机

基于 EasyTier 虚拟组网实现 P2P 联机。陶瓦大厅编号系统，支持 NAT 穿透和局域网广播模拟。

💾

存档备份

手动/自动备份存档，支持备份恢复、导出和完整性校验。版本隔离支持，自动清理过期备份。

快速开始

1. 下载安装 ​

前往 下载页面 选择适合你操作系统的安装包。

2. 启动 FMCL ​

安装完成后启动 FMCL，首次启动会自动检查运行环境。

3. 安装 Minecraft 版本 ​

在右侧面板输入版本号（如 1.20.4），可选安装模组加载器（Forge / Fabric / NeoForge），点击安装即可。

4. 启动游戏 ​

在已安装版本列表中选择要启动的版本，点击「🚀 启动游戏」按钮。
