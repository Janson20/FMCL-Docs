使用指南 ​

本文按实际操作流程介绍 FMCL 的界面与用法。功能清单与边界条件见功能一览， 配置项含义见配置说明。

首次启动 ​

  1. 启动 FMCL 后先显示启动画面，随后检查运行环境（数据目录、Java、图形后端）。
  2. 首次运行会依次弹出语言选择、使用条款与公告确认；同意后进入主界面。
  3. 主界面左侧是一级导航，按「游戏 / 资源与联机 / 工具与扩展」分组；当前平台不可用的领域（如非 Windows 的已安装基岩版）不会出现。
  4. 顶栏右侧提供搜索、公告、更新检查与设置入口，底部状态栏显示任务进度与操作结果。

安装游戏版本 ​

  1. 左侧导航进入「已安装版本」，点「安装新版本」。
  2. 输入版本 ID（如 1.20.4），或切到「正式版 / 测试版」标签页点选回填（每页 20 条）。
  3. 选择模组加载器：无、Forge、Fabric、NeoForge、Quilt、LiteLoader、LegacyFabric、Cleanroom、OptiFine。 选择加载器时原版 Minecraft 会并行安装，并自动查询该加载器与游戏版本的兼容性。
  4. 点「安装版本」，进度卡显示总进度、当前文件、下载速度与剩余项，可随时取消。
  5. 安装完成后回到版本列表，刷新即可看到新实例。

加载器安装完成后会为该实例启用版本隔离，创建独立的 mods/、config/、saves/ 等目录。 国内网络建议在设置中保持「国内镜像」开启，镜像覆盖版本清单、游戏资源、库文件与加载器安装器。

启动游戏 ​

  1. 打开左侧导航「游戏」，在「最近使用版本」卡片点「启动游戏」；或进入「已安装版本」选中实例后启动。
  2. 启动前会检查 Java：默认自动扫描系统 Java 并匹配版本；也可在设置 → Java 中指定。
  3. 游戏运行期间按钮变为「强制结束游戏」，点击可结束该进程。
  4. 游戏窗口出现后启动器会按设置决定是否最小化，并关闭 stdout 管道以免拖慢最后加载阶段。

退出码非 0，或本次启动后新生成崩溃报告 / hs_err 时，会弹出诊断窗：可查看退出码、崩溃报告、游戏日志与 JVM 崩溃日志，导出诊断 ZIP，上传日志到 LogShare.CN，或登录净读账号后做 AI 分析。

管理已安装版本 ​

  • 版本行提供详情、模组、资源、重命名、删除与打开目录操作。
  • 重命名会同步修改文件夹名、版本 JSON 文件名与内部 id，已有资源不会丢失。
  • 删除前二次确认，并清理「最近使用版本」记录。
  • 校验功能用并发哈希检查实例文件完整性，结果回写到页面。

资源管理 ​

选中实例后进入「模组」或「资源管理」，可管理四类资源：

类型扩展名安装目录
模组.jar .zip，禁用后为 .jar.disabledmods/
资源包.zipresourcepacks/
地图.zip 自动解压或文件夹saves/
光影.zipshaderpacks/
  • 安装方式：拖拽文件到窗口，或点「选择文件安装」。
  • 模组卡片读取 jar 内元数据（图标、名称、作者、modid、版本）；资源包与光影从 zip 提取预览图。
  • 支持类型化搜索、分页、启用与禁用、删除、打开目录，以及把模组列表复制到剪贴板。
  • 「检查更新」同时查询 Modrinth 与 CurseForge，可勾选后批量更新，失败项保留已完成文件。

原版实例只显示资源包与地图；安装加载器后才出现模组与光影，与版本隔离规则一致。

在线资源浏览 ​

左侧导航进入「资源浏览」：

  1. 进入即加载热门内容；可切换模组、资源包、光影类型。
  2. 用关键词、游戏版本与加载器筛选；游戏版本与加载器默认按当前实例自动填好。
  3. 卡片刻显示名称、作者、下载量与简介；点开详情可选择具体版本、预览依赖并安装到指定实例。
  4. 安装时递归处理 required 依赖；找不到兼容版本时跳过并提示。
  5. 未配置 CURSEFORGE_API_KEY 时自动只查 Modrinth；登录净读账号后可使用 AI 搜索扩展关键词。

安装整合包 ​

在「已安装版本」→「安装新版本」→「安装整合包」中：

  1. 选择来源：本地 .mrpack / MultiMC / CurseForge / HMCL / MCBBS / 通用压缩包，或点「从在线浏览下载」。
  2. 程序解析元数据、可选组件与组件清单；.mrpack 的可选文件可勾选。
  3. 可自定义实例名（默认整合包名，冲突或非法名称会禁用开始按钮）。
  4. 点「开始安装」，等待并行阶段与加载器安装完成。
  5. 安装完成后自动刷新版本列表，可直接启动，也可进入资源管理。

自定义实例名会生成该实例自己的版本 JSON，版本列表、启动与资源管理都按这个实例识别； 这也是自定义名称的整合包实例能被正确识别的原因。

服务器 ​

安装与启动 ​

  1. 左侧导航进入「服务器」，点「安装服务器」。
  2. 输入版本 ID，或从正式版列表点选（每页 10 条）。
  3. 安装完成后在服务器列表点启动；可同时运行多台服务器。
  4. 首启会生成基础 server.properties 并同意 EULA；默认使用离线模式。
  5. 每台服务器可单独设置最大内存（1G 到 16G），保存在该服务器目录的 .fmcl_server.json。

端口被占用时启动器会自动顺延到空闲端口并回写配置，并在列表与详情页提示实际端口。

控制台 ​

服务器详情页的控制台显示运行状态、在线玩家与每 2 秒一次的内存采样；日志自动滚底，最多保留 5000 行。 底部命令框支持回车或按钮发送命令，也可清屏与导出日志。

配置编辑器 ​

点服务器行或详情页的配置按钮，按 7 类编辑 server.properties：

  • 支持按名称、键名（如 motd）或说明搜索，每个配置项显示中文名称、原始键名与一句话说明。
  • 数字项显示取值范围，越界时标红并弹窗提示。
  • 保存只更新改动过的键，保留注释与未知键；可单项或整类恢复默认。
  • 「原始文件」分类可直接编辑文本；页面对未保存修改启用离开守卫。

整合包开服 ​

在「服务器」→「安装服务器」旁可选用整合包开服，只接受 .mrpack。安装时会自动检测 Forge / Fabric / NeoForge / Quilt 服务端加载器，Fabric 缺少 Fabric API 时自动补装；用途不明的模组会在安装后集中列出，可逐项禁用。

陶瓦联机 ​

仅 Windows 可用。首次进入会检测并引导安装 EasyTier（多镜像测速，失败自动回退）。

创建大厅：

  1. 输入本地 Minecraft 端口（默认 25565）与显示名称。
  2. 点「创建大厅」，约 5 秒后就绪。
  3. 把生成的陶瓦编号（U/ 前缀 21 位）发给好友。

加入大厅：

  1. 输入编号与显示名称，点「加入大厅」。
  2. 建立连接后，在 Minecraft 多人游戏中连接 localhost 即可。
  3. 成员列表主机优先显示，底部实时显示与主机的延迟。

「扫描」按钮可发现同一局域网中的共享世界，只展示结果，不会自动进入。

存档备份 ​

左侧导航进入「存档」：

  1. 页面自动扫描全局 saves/ 与各实例隔离目录，刷新时重扫。
  2. 选中存档后可点「备份」，可填写备注，压缩进度真实显示。
  3. 备份列表显示时间、大小、游戏版本与备注，支持恢复、校验、导出 ZIP 与删除。
  4. 恢复前校验 ZIP 完整性，默认把当前存档重命名为 _bak_时间戳 保留。
  5. 页面底部可开启「启动游戏前备份」与「游戏退出后备份」，开关即时写入配置。

设置中可改备份路径、压缩等级（1 / 3 / 6 / 9）、每存档保留数量（5 / 10 / 20 / 30 / 50 / 不限）与恢复时旧存档处理方式。

音乐 ​

左侧导航进入「音乐」，「发现」首页展示每日推荐、推荐歌单、排行榜与最新音乐。

  • 本地音乐：选择文件夹后递归扫描 MP3 / FLAC / OGG / WAV / M4A / AAC，读取标签与内嵌封面，可「播放全部」。
  • 在线搜索：同时查询网易云、QQ、酷我、酷狗、咪咕，B 站作为跨源兜底；自动选择可用最高音质。
  • 歌单：全部歌曲、我喜欢的音乐、最近播放、自建歌单与网易云歌单；支持排序与「播放全部」。
  • 歌词：LRC、翻译与罗马音；桌面歌词三行滚动，可锁定与解锁拖拽、调透明度。
  • 热键：Ctrl+Shift+Space 播放与暂停、Ctrl+Shift+Left/Right 切歌、Ctrl+Shift+Down 停止、 Ctrl+Shift+Up/PageDown 音量、Ctrl+Shift+Alt+M 静音。

播放失败时会自动跨源搜索同曲，并用时长校验排除翻唱与伴奏；Windows 上同时支持系统媒体控制 SMTC。

工具箱 ​

左侧导航进入「工具」。九个小工具：清理游戏垃圾、端口检测、Hash 计算、坐标转换、今日人品、冷知识、 知识问答、多线程下载、相关网站。

性能监控：按 Ctrl+Shift+M 或点顶栏监视器按钮打开悬浮窗，显示 CPU、内存与 GPU 数据，可拖拽并记住位置。

成就与签到 ​

左侧导航进入「成就总览」，显示 47 项成就的总进度与 9 个分类，卡片带进度与阶段。 解锁成就会在右下角提示；首页显示连续签到天数。登录净读账号后可在「云端」分类做云存档同步。

AGENT 与语音 ​

左侧导航进入「AGENT」：

  1. 左侧会话列表可新建、切换、重命名、删除会话，历史自动保存。
  2. 在输入框描述需求，例如「帮我安装 1.20.4 的 Fabric 版本」。
  3. 工具调用会显示参数与结果；高危命令、文件修改与提问都需要二次确认，文件写改删会先预览 diff。
  4. 右上可选择提供商与模型；设置 → AI 中可配置 API Key、端点、思考强度和工具权限。

顶栏快速输入框按 Enter 会直接跳到 AGENT 并发送。输入框旁的语音按钮使用 SenseVoice 离线模型做语音输入， 首次使用会自动下载模型。

命令行同样可用：

bash
uv run python main.py --agent "帮我安装最新版"
uv run python main.py -A

基岩版 ​

仅 Windows 10 19041 及以上。左侧导航进入「已安装基岩版」：

  1. 在版本库中搜索或筛选 UWP / GDK，每页 20 条。
  2. 首次安装需要同意 MCAPPX 条款；GDK 会检测 .NET 10 SDK 并提供下载引导。
  3. 安装使用真实进度与断点续传，完成后可直接启动。
  4. 已安装卡片支持启动、删除、详情与打开版本目录。

设置与账号 ​

设置分区 ​

左侧导航进入「设置」，共 9 个分区：启动器、Java、主题、音乐账号、日志、关于、账号、AI、插件。 改动先进入草稿，可预览主题与语言，点保存才写盘；带未保存修改离开会提示。

账号 ​

  • 微软正版：默认使用 PKCE OAuth，另提供设备代码登录。
  • 离线：本地生成 UUID，无需联网。
  • Yggdrasil：连接皮肤站等第三方验证服务器时自动注入 authlib-injector。

账号可添加、删除、切换与设为当前，也支持导入导出加密的 .fmcl_accounts 文件。角色名由当前账号决定。

主题与语言 ​

主题分区提供 5 套预设、导入 .json 主题、自定义 #RRGGBB 强调色与版本动态主题。 语言支持简体中文、English、繁體中文、日本語，切换即时生效。

插件 ​

在「设置」→「插件」打开插件管理器：

  1. 「从文件安装」选择 .fmpl 插件包，或在「插件市场」中浏览并一键安装。
  2. 列表显示名称、版本、作者与状态，可启用、禁用、卸载与查看权限。
  3. 启用与禁用均热加载，不需要重启；高风险权限每次使用都会弹窗确认。
  4. 提供 QML 页面的插件会出现在侧栏底部的「插件」分组。

插件开发见插件开发指南。

更新 ​

Windows 上启动器会在启动时检查更新（可在设置中关闭）。发现新版本时会显示版本号与更新日志， 也可在「设置 → 关于」中手动检查、下载并启动安装包。

Linux 与 macOS 不提供自动安装：Linux 可用一键安装脚本或重新下载 tarball，macOS 请从源码更新。
