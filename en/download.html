Installation Guide ​

Windows

Double-click the `.exe` installer and follow the wizard. The installer bundles 7-Zip so no internet connection is required.

macOS

Double-click the `.dmg` file and drag FMCL.app into the Applications folder.

If you see an unidentified developer warning on first launch, go to System Settings > Security & Privacy and click "Open Anyway", or run:

bash
xattr -cr /Applications/FMCL.app

Linux (DEB)

bash
sudo dpkg -i FMCL-x.x.x-linux-amd64.deb

Linux (AppImage)

bash
chmod +x FMCL-x.x.x-x86_64.AppImage
./FMCL-x.x.x-x86_64.AppImage

From Source

bash
git clone https://github.com/Janson20/FMCL.git
cd FMCL
pip install -r requirements-windows.txt
python main.py
