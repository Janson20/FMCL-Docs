FMCLFusion Minecraft Launcher

A Minecraft launcher built on Qt Quick (QML), covering version management, the mod ecosystem, server hosting, multiplayer, backups, music, achievements and an AI assistant

Download
Features
Guide

Twelve feature areas

Versions and launching

Install vanilla plus eight mod loaders, detect nine loaders, rename and verify instances. Java is matched automatically and crashes are collected with optional AI diagnosis.

Resources and modpacks

Manage mods, resource packs, worlds and shaders in one place. Browse Modrinth and CurseForge, install six modpack formats and host .mrpack servers.

Servers

Install, start and control servers with per-server memory. Ports are remapped automatically, server.properties gets a visual editor and server-side mods are managed too.

Terracotta multiplayer

P2P multiplayer over EasyTier with NAT traversal and LAN broadcast emulation. 21-character Base34 lobby codes, interoperable with HMCL and PCL CE rooms.

World backups

Manual and automatic backups with real progress, integrity checks, restore, export and retention rules. Restoring keeps the previous world as _bak_timestamp.

Music

Five online sources plus a Bilibili fallback, local scanning, playlists, lyrics and desktop lyrics. SMTC and global hotkeys on Windows, loudness normalisation across tracks.

Toolbox

Clean up junk files, test ports, hash files, convert coordinates, daily luck, trivia, quizzes, a multi-threaded downloader and a curated links page, plus a performance overlay.

Achievements

47 achievements across nine categories with staged upgrades, daily check-ins, unlock toasts and optional cloud sync.

AGENT and voice

Multiple providers, 33 tools, three permission levels and Skills. Offline SenseVoice dictation lets you talk straight into the input box.

Bedrock Edition

Download, install and launch UWP and GDK builds with real progress and resumable downloads. Windows 10 19041 or later only.

Plugin system

Plugins distributed as .fmpl, 20+ hooks and three permission levels, with hot reloading, dependency resolution and a marketplace. QML pages use ui_api: 2.

Themes and languages

Five themes, a custom accent colour and version-driven theming. Switch between Simplified Chinese, English, Traditional Chinese and Japanese at runtime.

Quick start ​

1. Download and install ​

Pick your platform and installer on the download page. The Windows installer bundles 7-Zip, so a double-click is all it takes.

2. Install a game version ​

Open Installed versions in the sidebar and click Install a new version. Enter a version ID such as 1.20.4, or pick one from the release or snapshot lists, choose a mod loader if you need one and start the install.

3. Launch the game ​

Open Game in the sidebar and click Launch on the recently used version card. You can force-stop the game at any time, and an abnormal exit opens the crash diagnostics.

4. Explore ​

Resources, servers, multiplayer, backups, music, AGENT and plugins are all one sidebar click away.
