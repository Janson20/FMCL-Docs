FMCL⛏ Fusion Minecraft Launcher

A feature-rich Minecraft launcher with modern CustomTkinter UI, China mirror acceleration, multi-mod loader support and version management

🎮

Version Management

Browse and install all Minecraft versions (release + snapshot). One-click version selection and launch with paginated browsing.

⚡

China Mirror Acceleration

Built-in BMCLAPI mirror for dramatically faster downloads in China. One-click mirror toggle covering manifests, assets, libraries and more.

🔧

Multi-Mod Loader

Supports Forge, Fabric, and NeoForge. Vanilla Minecraft is automatically installed in parallel when installing mod loaders.

🧩

Modrinth Mod Browser

Integrated Modrinth API for online mod search and installation. AI-powered keyword optimization for better search coverage.

📦

Modpack Install & Server

Install .mrpack modpacks or deploy them as dedicated servers. Parallel installation with automatic dependency resolution.

🖥

Server Management

Dedicated server tab for downloading and running Minecraft servers. Smart Java detection, real-time log monitoring, memory tracking.

🌐

Terracotta Multiplayer

P2P multiplayer via EasyTier virtual networking. Terracotta lobby code system with NAT traversal and LAN broadcast simulation.

💾

World Backups

Manual and automatic world backups with restore, export, and integrity verification. Auto-cleanup of expired backups.

Quick Start

1. Download & Install ​

Go to the Download page and pick the installer for your operating system.

2. Launch FMCL ​

Start FMCL after installation. The first launch will automatically check the runtime environment.

3. Install a Minecraft Version ​

Enter a version ID (e.g. 1.20.4) in the right panel. Optionally select a mod loader (Forge / Fabric / NeoForge), then click Install.

4. Play ​

Select your installed version from the list and click the 🚀 Launch button.
