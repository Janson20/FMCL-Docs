Configuration ​

This page lists the configuration file locations, platform differences and every persisted setting. The launcher reads and writes the configuration itself, so you rarely need to edit it by hand; quit the launcher first if you do.

Configuration file locations ​

Windows / macOS ​

The launcher prefers the directory where the program is installed (portable mode):

ContentPath
Configurationconfig.json
Key.fmcl_key
Loglatest.log
Structured loglatest_structured.log
Minecraft.minecraft/

When the program directory is not writable (for example, when installed under the system program directory), the launcher falls back to the user data directory:

  • Windows: %LOCALAPPDATA%\FMCL
  • macOS: ~/Library/Application Support/FMCL

On the first fallback, any configuration, accounts, world saves, playlists and other data already in the original directory are copied to the new one; the original directory is kept.

Linux ​

Follows the XDG Base Directory specification:

ContentPath
Configuration~/.config/fmcl/config.json
Key~/.fmcl/.fmcl_key
Log~/.local/share/fmcl/fmcl.log
Runtime data~/.fmcl/
Minecraft~/.minecraft/

Directories are created on the first run. Running from source requires Python 3.10–3.11 and the Qt 6 runtime libraries.

Downloads and updates ​

EntryTypeDefaultDescription
mirror_enabledbooltrueUse the BMCLAPI China mirror
download_threadsint4Number of threads used for multi-threaded downloads
auto_check_updatebooltrueCheck for updates silently after startup
minimize_on_game_launchboolfalseMinimize the launcher once the game has started

Accounts and player ​

EntryTypeDefaultDescription
player_namestring"Steve"Legacy player name, used only to migrate to an offline account on the first run
skin_pathstring/nullnullPath to the current skin file
accounts_filestring/nullnullAccount file path; null uses accounts.json in the data directory
current_account_idstring/nullnullID of the current account
account_migration_doneboolfalseWhether the legacy player name has been migrated; internal flag

Interface and language ​

EntryTypeDefaultDescription
languagestring"zh_CN"Interface language: zh_CN / zh_TW / en_US / ja_JP
language_chosenboolfalseWhether the first-run language selection has been completed
theme_namestring"default"Theme name: default / ocean / forest / lavender / sunset, or an imported theme name
accent_colorstring/nullnullCustom accent color as a hex value; null uses the theme default
dynamic_version_themeboolfalseAdjust the accent color to the current Minecraft version
overlay_geometryobject{}Position, size and opacity of the desktop lyrics and performance overlay windows, keyed by window name

Terms and privacy ​

EntryTypeDefaultDescription
terms_consentboolfalseWhether the terms of use and the Minecraft EULA have been accepted
ai_privacy_consentboolfalseWhether the log upload notice for AI analysis has been accepted
bedrock_terms_acceptedboolfalseWhether the Bedrock Edition terms have been accepted
bedrock_components_consentedboolfalseWhether downloading GDK-certified components on demand has been approved

Java ​

EntryTypeDefaultDescription
java_modestring"auto"auto scans automatically / system uses system Java / custom uses a custom path
java_custom_pathstring/nullnullPath to a custom Java executable

Backups ​

EntryTypeDefaultDescription
backup_dirstring/nullnullBackup directory; null uses backups/ in the data directory
backup_compress_levelint6ZIP compression level: 1 is fastest, 9 gives the smallest file
backup_max_per_worldint10Number of backups kept per world save; 0 means unlimited
backup_restore_modestring"rename"What happens to the old world save on restore: rename / overwrite / trash
backup_auto_launchboolfalseBack up automatically before the game starts
backup_auto_exitboolfalseBack up automatically after the game exits

Music and credentials ​

EntryTypeDefaultDescription
music_stateobject{}Playback state such as volume, play mode and last directory
music_baike_original_enabledbooltrueQuery Baike as a fallback when the original artist cannot be determined
wy_cookiestring/nullnullNetEase Cloud Music login cookie, stored after Fernet encryption
jdz_tokenstring/nullnullJingdu AI token, stored after Fernet encryption
jdz_usernamestring/nullnullJingdu AI username, stored after Fernet encryption

jdz_token, jdz_username and wy_cookie are stored as ciphertext in the file and cannot be copied for direct use. Editing them by hand makes decryption fail, and the launcher then treats you as signed out; sign in again through the interface.

Runtime directories ​

The following directories are not configured in config.json; they are derived from the data directory:

ContentLocation
Game versions.minecraft/versions/
Mods and resourcesmods/, resourcepacks/, shaderpacks/ and saves/ of the corresponding version
Accountsaccounts.json
Achievementsachievements.db
Pluginsplugins/ (configuration and data are split into per-plugin directories by plugin ID)
Musicdata/music/
Backupsbackups/ or backup_dir
Themesthemes/
Logslatest.log, latest_structured.log

Restoring defaults ​

  • A single setting: click "Restore defaults" in the corresponding section of Settings, or set the value back by hand.
  • All settings: quit the launcher, back up config.json and delete it; the default configuration is generated again on the next start.
  • Accounts, achievements, world saves and playlists are not stored in config.json, so deleting the configuration does not delete that data.
