## System requirements

| Platform | Notes |
|----------|-------|
| Windows 10 / 11 x64 | NSIS installer, installs per user into `%LOCALAPPDATA%\Programs\FMCL` with no administrator rights |
| Linux x86_64 | Directory tarball or the install script; needs the Qt 6 runtime and XCB packages |
| macOS | No binary build yet; run from source |
| Windows 32-bit | No build since 3.0.0; keep using 2.12.6 |

| Dependency | Notes |
|------------|-------|
| Java | 8 or newer; the launcher scans for installed Java runtimes, and the recommended version depends on the Minecraft version |
| Python | Needed only to run from source, version 3.10–3.11, dependencies managed by uv |

## Quick start

### 1. Download and install

Pick your platform and installer on the [download page](/en/download). The Windows installer bundles 7-Zip, so a
double-click is all it takes.

### 2. Install a game version

Open **Installed versions** in the sidebar and click **Install a new version**. Enter a version ID such as
`1.20.4`, or pick one from the release or snapshot lists, choose a mod loader if you need one and start the install.

### 3. Launch the game

Open **Game** in the sidebar and click **Launch** on the recently used version card. You can force-stop the game at
any time, and an abnormal exit opens the crash diagnostics.

### 4. Explore

[Resources](/en/features#resources-and-modpacks), [servers](/en/features#servers),
[multiplayer](/en/features#terracotta-multiplayer), [backups](/en/features#world-save-backups),
[music](/en/features#music), [AGENT](/en/features#agent-and-voice) and
[plugins](/en/features#plugins-updates-and-system-integration) are all one sidebar click away.
