# ℹ️ About FMCL

FMCL (Fusion Minecraft Launcher) is a feature-rich Minecraft launcher built with the CustomTkinter modern UI framework. It supports China mirror acceleration, multi-mod loader installation, modpack management, and server deployment.

## 📊 Project Info

| Item | Detail |
|------|--------|
| Language | Python 3.10+ |
| UI Framework | CustomTkinter |
| License | GPL-3.0 |
| Platforms | Windows / macOS / Linux |
