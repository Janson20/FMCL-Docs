ℹ️ 关于 FMCL ​

FMCL (Fusion Minecraft Launcher) 是一个功能丰富的 Minecraft 启动器，基于 CustomTkinter 现代化 UI 框架构建。支持国内镜像加速、多模组加载器安装、整合包管理与服务器部署。

📊 项目信息 ​

项目信息
开发语言Python 3.10+
UI 框架CustomTkinter
许可证GPL-3.0
支持平台Windows / macOS / Linux
