3.0.0（2026-11-15） ​

3.0.0 是界面与打包体系的大版本更新。启动器完整迁移到 Qt Quick / QML，原有的版本管理、资源与整合包、 服务器、联机、备份、音乐、AGENT、语音、成就、插件与基岩版能力继续保留，并统一到新的界面与交互结构中。

全新 Qt Quick 界面 ​

  • 使用 QML 与 FluentUI 重做窗口、导航、页面、对话框与浮层。
  • 一级导航按「游戏 / 资源与联机 / 工具与扩展」分组，支持面包屑、页面栈与 fmcl:// 深链。
  • 12 个功能域统一使用页面骨架与 ready / loading / empty / error 三态，页面、主题与语言切换不再重建整套窗口。
  • 5 套主题、自定义强调色、版本动态主题与四语言运行时切换继续可用。
  • 启动画面、协议与公告链条、主窗口失败兜底统一由启动控制器管理。

版本、资源与服务器 ​

  • 原版与 8 种模组加载器安装，支持 9 种加载器识别、重命名、校验与删除。
  • Modrinth 与 CurseForge 双源资源浏览、依赖安装、详情页与批量更新。
  • 六种客户端整合包安装，以及 .mrpack 整合包开服。
  • 服务器安装、启动、控制台、每服独立内存、端口自动防冲突、server.properties 可视化编辑、服务器模组与资源包管理。
  • EasyTier 陶瓦联机，存档手动与自动备份、校验、恢复、导出。
  • 基岩版 UWP / GDK 下载、安装与启动，仅支持 Windows 10 19041 及以上。

音乐、AGENT 与插件 ​

  • 音乐页重做：发现首页、五大在线音源与 B 站兜底、歌单、歌词、桌面歌词、播放队列与全局热键。
  • Windows SMTC 系统媒体控制、媒体键与进度同步。
  • AGENT 支持多提供商模型、33 个工具、三级权限、Skills、流式输出与工具确认。
  • SenseVoice 离线语音输入，支持模型下载与本地 ZIP 导入。
  • 新增插件管理器、插件市场与 QML 页面扩展协议 ui_api: 2。
  • 插件页面可登记到一级导航，通过 Plugins.call 取数、emit_ui_event 推送刷新。

打包与安装 ​

  • Windows 提供 x64 NSIS 安装包，按当前用户安装，无需管理员权限。
  • Linux 提供 x86_64 目录产物 tarball，并可通过 scripts/install.sh 从源码或 tarball 安装。
  • 安装包补齐 FluentUI QML 插件 DLL，修复安装后启动时「QML 根对象未能创建」的问题。
  • Windows 构建日志、Linux Qt 插件定位、产物清单与 CUPS 依赖问题一并修复。

升级说明 ​

  • 可直接安装 3.0.0，安装目录与用户数据路径保持不变；卸载不会递归删除用户数据。
  • 升级前建议备份 config.json、accounts.json、.minecraft 与音乐数据目录。
  • 回滚方式：卸载 3.0.0 后再安装 2.12.6。
  • Windows 32 位不再提供 3.0.0 产物，请继续使用 2.12.6。
  • CustomTkinter 界面与 ui_backend 开关已移除，当前只提供 QML 界面；命令行模式仍在 main.py。
  • 声明 ui_api: 1 的插件界面页面不再加载，非 UI 钩子不受影响；QML 页面请使用 ui_api: 2 与 ui.page.register。
  • 独立 FMCL-Agent.exe 不再随包提供，CLI 模式使用 python main.py -A 或 python main.py --agent "指令"。

已知限制 ​

  • macOS 暂不提供 .dmg 或二进制包，只支持从源码运行。
  • Linux 目前只提供 x86_64 产物，暂无 ARM64 二进制。
  • Linux 非 root 环境下全局热键可能不可用，不影响其他功能。
  • 在线音乐与资源搜索依赖第三方接口，接口变动或网络限制可能导致个别来源暂时不可用。
  • GDK 基岩版首次使用可能需要 .NET 10 SDK，精简版安装包不内置 SDK。
